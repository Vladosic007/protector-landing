# Protector — лендинг бронеплёнки

Одностраничный сайт компании по установке бронеплёнки на окна
(противоосколочная плёнка класса P2A, 300 мкн) — Таганрог и область.

## Технологии
Чистый HTML / CSS / JS, без сборки. Шрифты — Google Fonts (Golos Text, Unbounded).

## Структура
- `index.html` — разметка всех секций
- `styles.css` — тёмная тема, адаптив, анимации
- `script.js` — меню, калькулятор, форма (заявки → Google Таблица), reveal-анимации
- `assets/` — favicon и og-картинка

## Локальный запуск
Любой статический сервер, например:

    python -m http.server 5500

Затем открыть http://localhost:5500

## Деплой
GitHub Pages: ветка `main`, папка `/` (корень).
